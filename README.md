# Nightwalker Epona

Undead Epona for [Dusklight](https://github.com/TwilitRealm/dusklight). She uses a new model on her original rig, so all her animations still work.

## Install

Download the `.dusk` from [Releases](../../releases). Drop it onto the Dusklight window or copy it into your mods folder, then enable it in the Mods menu.
